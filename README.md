# Рука на пульсе — демо финансового дашборда

Интерактивный проект для портфолио Екатерины Яхонтовой: управленческий обзор финансов группы компаний.

**Все компании, контрагенты, договоры, суммы и операции вымышлены.** Это самостоятельное демо, без подключения к Финтабло, 1С и другим источникам рабочих данных. Секреты и переменные окружения не требуются.

## Что можно попробовать

- **Деньги:** поступления, выплаты, административные расходы, налоги, финансовые платежи; график и иерархическая таблица.
- **НДС по оплатам:** расходы по ставкам 22%, 20%, 7%, 5%, без НДС; налоги и внутренние переводы отдельно.
- **НДС по 1С:** демонстрационная модель проводок, начислений, вычетов и остатка счёта 68.02.
- **Взаиморасчёты по 1С:** поставщики → договоры, долг, оплаты, поставки и отдельные авансы.
- **Переводы:** направления внутри группы и расшифровка операций.

Фильтры периода, города и нескольких компаний, раскрытие строк, модальные расшифровки, сравнение периодов, Excel/CSV. Демо охватывает июль–ноябрь 2026 года; стартовый экран показывает III квартал. Настоящие подключения не предлагаются.

## Запуск

Node.js 22.13+:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm start
```

Next.js App Router, React, TypeScript, CSS, Lucide, ExcelJS. Синтетический набор генерируется в `lib/demo-reports.mjs`; API возвращает только эти данные и не делает внешних запросов. Загрузка отчётов и клиентские фильтры используют ту же модель, что отображается в таблицах и Excel. Проверяются уникальность операций, ставки НДС и согласованность остатков.

Публикация: отдельный проект Vercel, framework Next.js, build command `npm run build`, Git branch `main`. Не добавляйте к этому публичному демо реальные реквизиты или финансовые выгрузки.
